Shopline UET Tag Overview

Shopline is a leading e-commerce platform for cross-border sellers. Deploying Bing Ads UET tags on Shopline enables you to track conversions from your Microsoft Advertising campaigns.

Prerequisites

  • Microsoft Advertising account with UET tag created
  • Shopline store with admin/developer access
  • UET tag JavaScript code from Microsoft Advertising

Deployment Steps

Step 1: Create UET Tag in Microsoft Advertising

  1. Sign in to Microsoft Advertising
  2. Go to Tools → UET tags → Create UET tag
  3. Name it (e.g., "Shopline Store UET")
  4. Copy the JavaScript code

Step 2: Install on Shopline

  1. Log in to Shopline admin
  2. Go to "Settings" → "Store Settings" → "Third-party Tracking"
  3. Add a new tracking code in the "Header" section
  4. Paste the UET tag JavaScript
  5. Save and publish

Step 3: Configure Conversion Events

EventTrigger PageEvent Type
Page ViewAll pagesAutomatic (base tag)
PurchaseOrder confirmationCustom event with revenue
Add to CartCart pageCustom event
View ProductProduct detail pageCustom event

Step 4: Create Conversion Goals

  1. In Microsoft Advertising, go to Tools → Conversion goals
  2. Create goals for each event (Purchase, Add to Cart, etc.)
  3. Map goal type to event parameters
  4. Set conversion value for revenue tracking

Step 5: Verify with UET Tag Helper

Install the UET Tag Helper Chrome extension and visit your Shopline store to verify all events fire correctly.

Common Issues

  • Tag not on all pages: Ensure the code is placed in the global header, not per-page
  • Purchase event not firing: Check if the order confirmation page has the event code
  • Revenue not tracked: Ensure revenue variable is passed in the event
