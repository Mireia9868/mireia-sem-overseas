Comparison Overview

Microsoft Advertising offers three ways to promote apps. Each has different placement, targeting, and optimization capabilities.

Feature Comparison

FeatureApp Install AdsMicrosoft Store AdsApp Extensions
PlacementSearch networkMicrosoft StoreBelow search ad
ObjectiveApp downloadsStore visibilityDrive app + web traffic
PlatformiOS & AndroidWindows appsiOS & Android
Campaign TypeStandalone campaignStandalone campaignAd extension
TrackingApp install trackingStore analyticsApp install + web conv.

App Install Ads

Dedicated campaign type for driving app downloads. Ads appear on the Microsoft Search Network with direct links to app stores.

  • Best for: Pure app install campaigns
  • Targeting: Device, OS, location, demographics
  • Bidding: CPC or target CPA

Microsoft Store Ads

Promote Windows apps within the Microsoft Store. Ads appear when users browse or search the Store.

  • Best for: Windows desktop/tablet apps
  • Targeting: Device type, market
  • Bidding: CPC

App Extensions

Add app download links as extensions to existing search ads. Users see both your website link and app download link.

  • Best for: Dual-purpose campaigns (web + app)
  • Targeting: Inherits from parent campaign
  • Bidding: No additional bid — extension clicks charged at normal CPC

Recommendation

For cross-border advertisers promoting mobile apps:

  1. Use App Install Ads for dedicated app campaigns with clear CPA targets
  2. Use App Extensions to supplement existing search campaigns
  3. Use Microsoft Store Ads only if you have Windows-specific apps
