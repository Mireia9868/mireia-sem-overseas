Shoplazza UET Tag Overview

Shoplazza (also known as Dianjiang) is a popular cross-border e-commerce platform. Deploying Bing Ads UET tags on Shoplazza enables conversion tracking for your Microsoft Advertising campaigns.

Prerequisites

  • A Microsoft Advertising account with UET tag created
  • A Shoplazza store with admin access
  • Your UET tag ID (found in Microsoft Advertising → Tools → UET tags)

Deployment Steps

Step 1: Get Your UET Tag

  1. Sign in to Microsoft Advertising
  2. Go to Tools → UET tags
  3. Click "Create UET tag"
  4. Name your tag and click "Save"
  5. Copy the JavaScript tag code

Step 2: Add UET Tag to Shoplazza

  1. Log in to your Shoplazza admin panel
  2. Go to "Settings" → "Analytics & Tracking"
  3. Find the "Custom Code" or "Head Code" section
  4. Paste the UET tag JavaScript in the header section
  5. Save changes

Step 3: Set Up Conversion Goals

  1. In Microsoft Advertising, go to Tools → Conversion goals
  2. Create a new goal for "Purchase" or "Add to Cart"
  3. Set the goal type to "Event" or "Destination URL"
  4. Configure the event parameters (category, action, value)

Step 4: Verify Installation

Use the UET Tag Helper browser extension to verify your tag is firing correctly on all pages:

  • Homepage (pageview event)
  • Product page (view item event)
  • Cart page (add to cart event)
  • Checkout/Thank you page (purchase event)

Troubleshooting

IssueSolution
Tag not firingCheck if code is in the correct section; clear cache
No conversions recordedVerify goal configuration matches your event parameters
Tag fires on wrong pagesCheck for conditional placement rules
