QUICK GUIDE

Use when

Tracking code is deployed and you need realistic-looking form data to confirm the conversion fires and the fields arrive correctly.

Best practice

Run the test in your platform's test or sandbox mode first. Use the generated details as filling reference, then check the captured event in your analytics or tag debugger before going live. If tax calculation blocks a test order in the US, tick the no-state-sales-tax option and pick Delaware or Oregon.

Watch out

All records are fictional; card numbers are public non-functional test values and the SSN uses an SSA-reserved prefix. Never use them for real accounts. The no-state-sales-tax filter applies to the US only; Alaska and Montana can still have local taxes.
