Automated Bidding Overview

Google Ads automated bidding uses machine learning to optimize bids for each auction, saving time and improving performance. The system analyzes millions of signals in real-time to set the optimal bid.

Bidding Strategies by Goal

Smart Bidding

Smart Bidding refers to Target CPA, Target ROAS, Maximize Conversions, and Maximize Conversion Value. These strategies use auction-time signals:

  • Device
  • Location & language
  • Browser
  • Time of day & day of week
  • Remarketing list
  • Recent search queries

Prerequisites for Success

  1. Conversion tracking: Must be properly set up and recording data
  2. Sufficient data: At least 30 conversions in the past 30 days for Target CPA; 50+ for Target ROAS
  3. Accurate conversion values: For Target ROAS, each conversion must have a value
  4. Campaign stability: Avoid frequent changes to settings, budget, or structure

Common Pitfalls

  • Setting unrealistic targets: Target CPA that's too low will reduce volume
  • Frequent budget changes: Disrupts the learning phase
  • Insufficient conversion data: Leads to poor optimization
  • Ignoring seasonality: Adjust targets for seasonal variations
